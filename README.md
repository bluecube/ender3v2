# Enderstein

My Ender 3 v2 mainboard was overheating, so I decided to upgrade to BTT SKR 1.3
and do some other tweaks along the way.

This repository contains/will contain things I needed for that.

[CAD model](https://cad.onshape.com/documents/441e622ce5cc57765078d1cb/w/7bd16ef91ff9252bf1b25226/e/dbf9c60ae6e35f16df00eb14).

## Mods:
- SKR 1.3 mainboard
- TBG Air direct drive extruder with custom toolhead and print cooling duct
- RPi 4B running Klipper, Mainsail and Fluidd
  - Installed and configured using Ansible!
- New electronics copmpartments to fit the upgraded electronics
- Temperature controlled fan for the electronics
- LED bar on the gantry
- Webcam

## Mods in progress

- Z braces
